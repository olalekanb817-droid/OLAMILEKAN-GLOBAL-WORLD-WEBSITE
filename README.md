# OLAMILEKAN GLOBAL WORLD

Official website for OLAMILEKAN GLOBAL WORLD — a business connecting technology, commerce, African products, logistics, and international trade.

**Tagline:** One World. Your Vision.

## Website

The site is a static, single-page HTML website. Its entry point is `index.html`; styling and the small navigation/year script are included in that file. There are no build dependencies or server-side components.

## Run locally

Open `index.html` in a browser, or serve the repository directory with any static web server. For example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

The repository has GitHub Pages enabled. To publish this root-level static site, configure Pages to deploy from the `main` branch and `/ (root)` in **Settings → Pages**. After publishing, confirm the deployment status and test the public Pages URL on desktop and mobile.
